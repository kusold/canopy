# canopy

`canopy` is an exemplar service built on [grove](https://github.com/kusold/grove).

Use this repository to demonstrate framework features and usage patterns.
Canopy is a framework demo, not a product service. Its job is to prove Grove's
APIs, defaults, testing story, and upgrade path.

## Documentation

See [grove](https://github.com/kusold/grove#documentation) for framework
documentation, the implementation plan, and architecture decision records.
